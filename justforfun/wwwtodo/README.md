# WWWtodo — What · How · When to do

一个纯前端单页应用：番茄钟专注计时 + 专注记录统计 + 个人日记。
无需安装、无需构建、无需联网——一个文件夹就是全部。

## 功能清单

### 🍅 专注（计时器）
- 内置「经典番茄钟」（25 分钟工作 + 5 分钟休息），可新建 / 编辑 / 删除自定义计时器
- 支持**倒计时**与**正计时**两种模式；正计时达到目标时长后提示「已达标」，可继续专注
- 进度环呼吸动画、毫米级时间戳校准（切后台不误差）、暂停 / 继续 / 放弃
- 开始前填写「预计完成的内容」，结束后补记「实际完成的内容」并按 0~10 星（步进 0.5）打分
- 顶部今日概览：今日周期数、累计专注时长、平均星级

### 📊 记录（历史统计）
- 五张统计卡片：累计次数 / 时长 / 总星数 / 平均星级 / 连续专注天数
- **日视图**：当天每次专注的时间、时长、目标与完成内容、星级
- **周视图**：七天柱状图（hover 显示数值），周汇总与「最专注的一天」
- **月视图**：热力图，颜色越深代表当天专注越久
- 日历追溯面板：快速跳到任意有记录的日期
- **导出 / 导入**：一键备份全部数据为 JSON，可整体恢复

### 📔 日记
- 按日期书写，月历导航（有日记的日期带小圆点标记）
- 今日心情 emoji 选择（开心 / 平静 / 一般 / 低落 / 疲惫）
- 纸张横线质感编辑区，**800ms 防抖自动保存**，也可手动保存
- 连续记录天数徽章、「最近日记」速览

## 使用方法

- **方式一**：直接用浏览器打开 `index.html`（推荐 Chrome / Edge 等现代浏览器）
- **方式二**：双击 `start.bat`，自动用默认浏览器打开

无需任何服务器或依赖，双击即用。

## 数据说明

- 所有数据保存在浏览器 **localStorage** 中（键名前缀 `wwwtodo_`），不上传任何服务器
- 数据与浏览器绑定：换浏览器或清除站点数据会丢失，请定期备份
- 备份方式：「记录」页右上角 **导出数据**，下载 JSON 文件；恢复时点 **导入数据** 选择该文件（导入会整体覆盖当前数据，且不可撤销）

## 文件结构

```
WWWtodo/
├── index.html        应用外壳（品牌栏、导航、视图容器、弹窗/toast 根节点）

├── css/
│   ├── base.css      设计系统：CSS 变量、按钮、卡片、弹窗、toast
│   ├── timer.css     「专注」模块样式（.tm- 前缀）
│   ├── history.css   「记录」模块样式（.hs- 前缀）
│   └── diary.css     「日记」模块样式（.di- 前缀）
└── js/
    ├── storage.js    window.Store 数据层（localStorage 读写、导出导入）
    ├── app.js        window.App 应用壳（视图切换、弹窗、toast、格式化工具）
    ├── timer.js      window.Timer 专注计时模块
    ├── history.js    window.History 记录统计模块
    └── diary.js      window.Diary 日记模块
```
